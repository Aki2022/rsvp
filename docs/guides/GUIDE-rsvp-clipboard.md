# RSVP Clipboard for Raycast

## What It Does

RSVP Clipboard is a macOS Raycast Extension. It reads the latest plain-text clipboard content when launched, writes the snapshot to a private one-time file, and opens the packaged, signed `RSVPReader.app` through Launch Services. The app receives the file path and settings as launch arguments; clipboard text itself is never placed in process arguments. The input file is mode `0600` inside a mode `0700` temporary directory, and the Swift reader removes it after loading. The Raycast command removes the temporary directory after the reader reports that its window is ready. The app presents one token at a time in a centered, resizable AppKit window. `npm run dev` and `npm run build` compile and sign the app bundle before Raycast builds the Extension. The window starts up to 960 × 460 points, constrained by the active screen, and the displayed text scales and wraps to fit it.

Press `Space` to pause or resume from the same phrase; the remaining display interval is preserved and a pause indicator appears. Press `↑` / `↓` or `k` / `j` to adjust the current session's WPM by 25, within the 30–1200 range; the lower-left shows current speed. Press `←` / `→` or `h` / `l` to seek about 10 seconds backward or forward on the estimated reading timeline. The lower-right shows reading position / estimated total time, follows seeks, and freezes while paused; the final token's indefinite hold is excluded from the estimate. Changing WPM updates the estimate while preserving progress through the current phrase.

The final token remains visible until `Esc` or the window's close button closes the reader. Sentence and clause punctuation add a short pause.

Set the starting speed in **Raycast Settings → Extensions → RSVP Clipboard → Preferences → 読み上げ速度 (WPM)**. The default is 300 WPM. Enter an integer from 30 to 1200; the next run uses the saved value. Arrow-key changes apply only to the current run. WPM controls the interval between displayed chunks, so it is an approximate pace for Japanese phrase groups. The 10-second seek is approximate and uses current WPM, phrase lengths, and punctuation pauses.

Press `s` in the reader to summarize the launch-time clipboard text with the configured Claude Code-compatible CLI. The default command is `claude2`; **要約コマンド** in Raycast preferences accepts an executable name or an absolute path. RSVP creates the editable prompt at `~/Library/Application Support/RSVP Clipboard/summary.md` on first launch and preserves it on later launches. The file is read when `s` is pressed, so edits apply immediately. The summary appears in the same window and starts from its first phrase. `Space`, the arrow keys, HJKL, and the progress display continue to work. `Esc` closes the window and cancels a summary in progress. If generation fails, the reader shows `要約失敗`; press `Space` to resume the original text from where it stopped.

Press `f` to create a Japanese infographic from the original launch-time clipboard text and open it in the default browser. Diagram generation pauses RSVP at the current phrase and shows `図解中`; after the browser opens, RSVP returns to that phrase and stays paused. Return to RSVP and press `Space` to continue. The external browser is a separate app, so bring RSVP back to the front before pressing `Esc` to close the reader. Closing RSVP by `Esc` or the window close button cancels a running CLI process and deletes the generated HTML and its session directory immediately. The app keeps no permanent copy. If RSVP is force-quit or crashes, the next reader startup removes unlocked stale diagram sessions while preserving directories belonging to other live RSVP windows. The empty RSVP temp root is removed after the final normal close. An already-rendered browser tab may remain visible after its source file is deleted; the browser controls its own display and cache.

RSVP creates the editable diagram prompt at `~/Library/Application Support/RSVP Clipboard/diagram.md` on first launch and preserves later edits. `f` reads that prompt when pressed. The default prompt asks for a responsive, self-contained Japanese HTML diagram. The result is capped at 1.5 MB, written with owner-only permissions under the OS temporary directory, and opened through Launch Services. A restrictive Content Security Policy blocks scripts and network requests; generated links are rejected. The source text is treated as untrusted material, URLs are removed, and raw CLI output is never shown on failure. Diagram CLI output capture is also bounded to 1.5 MB, and oversized output is rejected. Diagram generation uses the same configured subscription CLI as summaries and does not use a direct API.

Press `q` to make a comprehension quiz from the original clipboard text, even while the original or summary is playing, paused, or finished. RSVP removes URLs before sending the source through the configured subscription CLI. The quiz appears in the same Reader window with the question and each choice as readable, wrapped text. Long questions or choices can be scrolled inside the quiz area. Press `a`, `b`, or `c` to choose; the first choice is locked and the verdict, correct choice, and explanation remain until `Space`. Space advances to the next question. The last answer also shows the score as correct / actual question count; Space returns to the previous reading position paused. Press `q` again after returning to start a fresh quiz. If the source supports fewer than ten distinct questions, RSVP shows the supported number; if it supports none, RSVP shows an insufficient-content message. Quiz generation errors are shown without displaying raw CLI output. `Space` returns to the reading session after an error, and `Esc` or closing the window cancels generation and closes RSVP. Questions and scores are not saved.

RSVP creates the editable quiz prompt at `~/Library/Application Support/RSVP Clipboard/quiz.md` on first launch and preserves later edits. `q` reads that prompt when pressed. The prompt requests up to ten distinct Japanese questions with three choices and one answer, grounded in the source. Quiz generation reuses the configured Claude Code-compatible subscription CLI and does not call a direct API.

The extension starts the configured local CLI only after `s`, `q`, or `f` is pressed. The packaged Swift app resolves the command and reads `HOME`, `PATH`, `CLAUDE_CONFIG_DIR`, and Claude.ai OAuth variables from an interactive login zsh, matching the environment used by Terminal. Only those allowlisted values are transferred to the CLI; startup output and credential values are never shown. The extension removes all `ANTHROPIC_*` variables, Bedrock/Vertex/Foundry/Claude Platform on AWS provider switches, and Bedrock API credentials. It does not run a separate authentication preflight; the CLI performs its normal authentication when a request starts. All three requests use non-interactive plain-text output, Claude Code safe mode and restricted mode, disable built-in tools and session persistence. Restricted mode skips user, project, and local settings that could add an API key helper or provider route; organization-managed Claude Code policy remains in force. On failure, the reader classifies known authentication, input-size, permission, argument, usage-limit, or connection errors using stderr first. An unclassified failure shows the exit code and stdin/stdout/stderr byte counts. Press `d` on a quiz CLI failure to inspect a locally held excerpt of standard error; press `d` again or Space to leave it. The excerpt omits stdout, replaces matching request fragments, paths, URLs, email addresses, and credential-like strings, and is limited to 320 characters. It is not saved or copied. Authentication errors also show `login-zsh`, whether the config directory is default or custom, whether OAuth environment values were present by category, and that Keychain status is unverified. It never shows environment variable names, paths, credential values, or raw CLI output. See the [Claude Code environment variables reference](https://code.claude.com/docs/en/env-vars) and [zsh startup files](https://zsh.sourceforge.io/Doc/Release/Files.html).

The helper resolves executable names with interactive login zsh, but runs the resolved executable directly; it does not evaluate aliases or functions. The same shell environment bridge applies when the preference contains an absolute executable path. A custom `CLAUDE_CONFIG_DIR` and Claude.ai OAuth access/refresh tokens and scopes are copied only from that login shell. `ANTHROPIC_*` variables, provider switches, and Bedrock API credentials are removed from the CLI environment. Failure diagnostics reveal only safe categories; they never show environment-variable names, paths, or values. Organization-managed Claude Code policy is outside the extension's control and still applies.

Authentication errors from the CLI are converted to a short, safe message with a limited environment summary. OAuth values in the secure Keychain are not inspected by the reader, so its status is reported as unverified. The raw CLI output and credential values are not displayed.

If the executable name cannot be resolved from Raycast, set **要約コマンド** to the executable's absolute path. Resolution errors distinguish an invalid setting, a command not found, and a file that cannot be executed; the raw path and CLI error text are not shown.

## Japanese Segmentation

When Natural Language recognizes the clipboard text as Japanese, `assets/rsvp.swift` uses `NLTagger` lexical classes to group reading tokens into short phrases. Particles and a small set of common auxiliary forms join the preceding token; adjacent nouns join while the phrase stays within `maximumJapanesePhraseLength` (12 Swift characters); a verb following a `て`/`で` connector joins that phrase. Punctuation remains attached to the preceding phrase.

These native rules approximate bunsetsu-like reading chunks; they are not a full Japanese grammar parser. Results depend on Apple's Natural Language tagging, so some compounds or auxiliary forms may still split unexpectedly. The reader removes URLs beginning with `http://`, `https://`, or `www.`, plus bare domain names with optional paths, before language detection. If the clipboard contains only URLs, the command asks for body text. This is a lightweight regex filter; unusual URL formats may remain. The existing 32-character `maximumTokenLength` split remains a final safeguard for unusually long tokens. English and other text keep the existing word-token behavior.

## How To Use

1. From the project folder, run `npm install` once and then `npm run dev` to load the local extension into Raycast.
2. In Raycast, set the preferred speed under **Settings → Extensions → RSVP Clipboard → Preferences**.
3. Copy text to the clipboard, search for **RSVP Clipboard**, and launch it.
4. Press `Space` to pause or resume. Use `↑` / `k` to raise speed, `↓` / `j` to lower it, and `←` / `h` or `→` / `l` to seek about 10 seconds. Press `s` for a Japanese RSVP summary or `f` for a browser infographic based on the launch-time clipboard text.
5. Press `Esc` or click the close button to stop reading. During summary or diagram generation, `Esc` also terminates the CLI process and removes diagram-session files.

## Maintenance Notes

The extension manifest and preferences are in `package.json`; the command entry point is `src/rsvp-clipboard.js`; the AppKit reader source and Japanese chunking rules are in `assets/rsvp.swift`; quiz presentation and wrapped-text layout are in `assets/RSVPQuizPresentation.swift`; keyboard mappings are in `assets/RSVPKeyAction.swift`; HTML validation and temp-file cleanup are in `assets/RSVPDiagramHTML.swift` and `assets/RSVPDiagramStore.swift`; the app-bundle build is in `scripts/build-reader-app.mjs`; and editable defaults are `assets/summary-prompt.md` and `assets/diagram-prompt.md`. npm compiles the source to `assets/RSVPReader.app` before development and production builds. Run `npm test` for the Python environment-bridge checks and the Swift quiz presentation, key, HTML, permissions, and cleanup harness. Update this guide if the launch flow, speed range or keyboard controls, chunking, summary or diagram behavior, or dismissal behavior changes.

## Known Limitations

- The extension is macOS-only because its reader uses AppKit and NaturalLanguage, and it requires Swift to be available.
- Japanese chunking uses lightweight NaturalLanguage heuristics, not a dedicated Japanese parser; review the displayed chunks on the text you read most often.
- It reads the clipboard once at launch; copying new text does not replace the text currently being read.
- The window opens on the display containing the mouse pointer and must be the active app to receive `Space`, arrow keys, and `Esc`.
- HJKL controls are app-local aliases. `j` is the speed-down key because the request listed `l` for both forward seek and speed down.
- The infographic is a static HTML page. It is not registered as a Claude Artifact and cannot use scripts, remote images, external fonts, or network resources.
- The automated suite does not exercise the complete Raycast → default-browser → `Esc` flow. Verify that interaction in a local Raycast session.
- Summary generation requires an installed, authenticated Claude Code-compatible CLI. The CLI is not bundled, and automated checks do not make real CLI requests; authentication, network, and billing behavior depend on the local CLI environment and its policies.
- Restricted mode skips user, project, and local CLI settings. Organization-managed settings still apply and are not inspected or changed by the extension.
