# RSVP Clipboard for Raycast

[English](README.md) | 日本語

RSVP Clipboard は、macOS の Raycast 拡張機能です。クリップボードのテキストを、サイズ変更できるネイティブウィンドウで短い語句ごとに表示します。読み上げ中の本文から、日本語の要約、理解度クイズ、静的な図解を作ることもできます。

## 主な機能

- クリップボードの内容を一定の速度で表示し、速度変更やおおよその位置移動を行う
- Reader 内で日本語の要約を作る
- Reader 内で選択式の理解度クイズを行う
- 静的な HTML 図解を作り、既定のブラウザで開く
- 要約・クイズ・図解のプロンプトを編集する

### キーボード操作

| キー | 操作 |
| --- | --- |
| `Space` | 一時停止・再開、クイズの解説から次の問題へ進む |
| `↑` / `↓`、`k` / `j` | 読み上げ速度を毎分25語ずつ上げる / 下げる |
| `←` / `→`、`h` / `l` | 約10秒前 / 後へ移動する |
| `s` | 日本語の要約を作る |
| `q` | 理解度クイズを作る |
| `a` / `b` / `c` | クイズに回答する |
| `f` | 図解を作ってブラウザで開く |
| `d` | クイズ生成失敗後に、伏字処理したCLIエラーの一部を表示する |
| `Esc` | Readerを閉じ、実行中のリクエストをキャンセルする |

## 動作要件

- macOS 15 以降
- Raycast
- Node.js と npm
- ネイティブReaderのビルド用に Swift と `codesign`（Xcode Command Line Tools で利用可能）
- 要約・クイズ・図解用の Claude Code 互換CLI。既定のコマンド名は `claude2`

## ローカルで起動する

```sh
npm install
npm run dev
```

初期速度は Raycast の **Settings → Extensions → RSVP Clipboard → Preferences → 読み上げ速度 (WPM)** で設定します。既定値は毎分300語で、30〜1200の整数を指定できます。矢印キーと HJKL による速度変更は、現在のReaderセッションにだけ適用されます。

既定のコマンドを Raycast から実行できない場合は、**要約コマンド** に実行ファイル名または絶対パスを設定してください。このコマンドは要約・クイズ・図解で共用します。編集可能なプロンプトは初回利用時に次の場所へ作成されます。

- `~/Library/Application Support/RSVP Clipboard/summary.md`
- `~/Library/Application Support/RSVP Clipboard/quiz.md`
- `~/Library/Application Support/RSVP Clipboard/diagram.md`

自動チェックを実行するには次のコマンドを使います。

```sh
npm test
```

## クリップボードとCLIに渡すデータ

Readerの起動時にクリップボードを読み取ります。本文は権限を制限した短時間の一時ファイルを通してネイティブReaderへ渡され、Readerが読み込んだ後に削除されます。起動後にコピーした別の内容へ、現在の読書セッションが切り替わることはありません。

取得した本文を設定済みCLIへ渡すのは、`s`、`q`、`f` を押したときだけです。このリポジトリからモデルAPIを直接呼び出すことはありません。設定したCLIは外部サービスへデータを送る場合があり、認証・通信・組織ポリシー・課金条件はCLI側の設定に従います。機密情報を扱う前に、その条件を確認してください。生成した図解は一時的な静的HTMLで、Readerを閉じるとローカルのファイルが削除されます。

## 現在の状態と制限

- このリポジトリは開発中の試作で、完成版ではありません。
- macOS専用です。日本語の語句分割は Apple Natural Language のヒューリスティックを使い、完全な日本語文法解析は行いません。
- クイズは現在、最大10問を受け付け、10問未満の結果も表示できます。10問固定の要件は未完了です。
- 図解は静的ページです。生成HTML内のスクリプト、リンク、外部フォント、外部画像、ネットワーク利用は許可されません。
- このリポジトリはソースとローカル開発手順を提供します。公開済みのバイナリ配布物はありません。

詳しい挙動と制限は、[RSVP Clipboard ガイド](docs/guides/GUIDE-rsvp-clipboard.md)を参照してください。

## ディレクトリ構成

- `src/` — Raycast コマンドとプロンプトファイルの初期化
- `assets/` — Swift Readerのソース、既定プロンプト、アイコン
- `scripts/` — ネイティブアプリのビルドスクリプト
- `tests/` — 補助機能とパッケージ動作のチェック
- `docs/guides/` — 利用・保守ガイド
